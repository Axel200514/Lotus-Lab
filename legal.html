Terms of Service

This application is a non-commercial educational project developed exclusively for personal study, web architecture experimentation, and technical learning. It functions solely as a client-side search interface querying public imageboard APIs (Safebooru / Danbooru).

  • Purpose: Developed strictly for educational research, web development practice, and personal non-commercial study.
  • Content Disclaimer: This project does not own, sell, host, or commercialize any of the indexed media assets.
  • Trademarks: All character designs, fictional universes, video game titles, and trademarks referenced in tags belong entirely to their original creators, studios, and copyright holders.

Privacy

No user accounts, database registrations, tracking pixels, or telemetry scripts are used.

  • Local Storage: Saved pins and recent queries are stored strictly in your browser (localStorage) on your own device.
  • Network Privacy: External image requests use no-referrer policies to prevent transmitting navigation headers.
  • Data Control: You can clear all locally saved data at any moment by resetting your browser site data.

Content & Takedown Notice

This application does not host, store, or upload media files to any private server or database. It operates strictly as a lightweight client proxy that displays metadata directly from public external imageboards (Safebooru).

Because no content is physically stored on or hosted by this personal study project, copyright owners seeking complete removal of an image must request removal directly from the upstream imageboard providers or the original hosting platform where the file is stored.

Artist Attribution

Artwork metadata is parsed to credit original creators. Whenever source information is available in the index, pin modals provide direct links to the author's original profiles (Pixiv, Twitter / X, ArtStation, DeviantArt, etc.) to drive discovery to their official pages.
